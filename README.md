## 🇨🇳 中文

把一段分镜表或剧本文字压缩成一张 3×3 网格故事板图片的生成提示词。每格布局严格统一：左上角是「镜号·景别·动作状态」，右上角是时间码，中央 60-70% 放主画面，底部是红色角色名标签加白色台词字幕。提示词开头先锁定一段全片共享的统一视觉锚点，把风格、调色、灯光和每个角色的完整外观写死，9 格全部继承，避免跨格换脸和色调乱跑。它坚持台词保真——不改名、不改台词、不改剧情，并强制排除水印、卡通化和顺序错乱。产出的图既可直接当 AI 视频的参考图，也能拿去审片沟通；分镜超过 9 个时按 9 镜一组拆成多张。

### ✨ 能做什么

- 分镜表 → 3×3 网格故事板提示词，9 格布局严格统一
- 每格自带镜号·景别·动作状态、时间码、主画面、角色名加台词
- 统一视觉锚点锁定风格 / 调色 / 灯光 / 角色外观，9 格复用防换脸
- 画幅比例与分辨率一律不写进提示词，交给生图工具界面设置
- 台词与分镜表 100% 一致，镜序、台词、剧情零改动
- 自带自检清单：排除水印、卡通化、顺序错乱与跨格换脸，超 9 镜自动拆多张

## 🇬🇧 English

Turns a shot list or script passage into a single 3x3 grid storyboard image prompt. Every cell uses the same strict layout: top-left holds shot number, shot size and action state; top-right holds the timecode; the center 60-70% carries the main frame; the bottom holds a red character-name tag with white dialogue subtitles. The prompt opens with a shared visual anchor that pins style, color grade, lighting and each character's full appearance, inherited by all 9 cells so faces and tones stay consistent across the grid. Dialogue is kept verbatim — no renaming, no rewriting, no plot changes — and watermarks, cartoon styling and out-of-order cells are explicitly excluded. The result works as a reference image for AI video or as a review board; sequences longer than 9 shots split into additional grids of 9.

### ✨ What it does

- Shot list to 3x3 grid storyboard prompt with a strictly uniform cell layout
- Each cell carries shot number, shot size, action state, timecode, main frame and character-plus-dialogue strip
- A shared visual anchor pins style, grade, lighting and character appearance reused across all 9 cells
- Aspect ratio and resolution are kept out of the prompt entirely, left to the image tool's UI
- Dialogue matches the shot list 100%, with zero changes to order, lines or plot
- Built-in self-check excludes watermarks, cartoon styling, wrong order and face drift; over 9 shots splits into more grids
